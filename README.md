# Hotel Management System 🏨

A Java-based desktop application for managing hotel operations, built with Java Swing.

## 💡 Features

- 🔐 User Login System
- 📋 Customer Information Management
- 🛏 Room Booking and Availability
- 🧹 Room Cleaning Status
- 🧾 Billing and Checkout
- 👨‍💼 Employee and Manager Info
- 🚗 Pickup Service Info
- 🧑‍💻 Admin Dashboard

## 🛠 Technologies Used

- Java
- Java Swing (GUI)
- JDBC (Database Connectivity)
- MySQL (as the backend database)
